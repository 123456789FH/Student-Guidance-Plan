مساعد الموجه الطلابي — الإصدار 4.0 الأمني
الخطة التفاعلية لبرامج التوجيه الطلابي والقيم

أهم الإضافات والتحسينات:
1) شعار التطبيق ظاهر في أعلى يمين الواجهة، ويمكن استبداله من إعدادات التقرير بشعار المدرسة/الجهة.
2) إعدادات تقرير جديدة تشمل: اسم مُعدّ التقرير، إدارة التعليم، اسم المدرسة، مدير المدرسة، العام الدراسي، وشعار التقرير.
3) تصدير كامل لبيانات الخطة بصيغة JSON وإعادة استيرادها لاحقًا.
4) تصدير التقرير الختامي بصيغة Excel (.xlsx) حقيقية ومتوافقة مع Excel.
5) تصدير التقرير الختامي بصيغة Word (.docx) حقيقية ومتوافقة مع Word.
6) استمرار الطباعة والحفظ PDF من المتصفح، والتقرير الأسبوعي والتقرير الختامي.
7) صور التوثيق أصبحت مؤقتة في ذاكرة الجلسة فقط، ولا تُخزن في IndexedDB أو localStorage، وتختفي عند تحديث الصفحة أو إغلاقها.
8) عند تشغيل الإصدار الجديد يحاول التطبيق حذف قاعدة صور التوثيق القديمة من الإصدارات السابقة.
9) رفع الصور مقيد إلى PNG/JPEG/WebP، بحد أقصى 5 م.ب للصورة، مع إعادة ترميز الصورة وعدم حفظ الملف الأصلي عند فشل المعالجة.
10) رفع شعار التقرير مقيد إلى PNG/JPEG/WebP بحد أقصى 2 م.ب، ويعاد ترميزه لإزالة البيانات الوصفية غير الضرورية.
11) ملف JSON لا يضم صور التوثيق المؤقتة، لكنه يحفظ إعدادات التقرير والشعار المختار.
12) فحص واستيراد JSON مع تحديد الحجم وتطهير الحقول قبل الحفظ.
13) حماية إضافية عبر Content Security Policy ومنع الاتصالات البرمجية الخارجية غير المطلوبة.
14) Service Worker مقيد بملفات التطبيق المعروفة فقط ولا يخزن أي طلب GET عشوائي.
15) شاشة استخدام آمن تظهر أول مرة للتأكيد على عدم إدخال بيانات شخصية أو حساسة.
16) زر مسح جميع البيانات يمسح الخطة وإعدادات التقرير ويحاول إزالة التخزين القديم للصور.
17) التذييل ثابت: أ/ فاطمة هزازي فقط.

ملاحظات أمنية مهمة:
- التطبيق مساعد مستقل للتخطيط والتوثيق، وليس جزءًا من نظام نور ولا يوجد ربط تقني أو نقل بيانات إليه.
- لا تدخل أسماء الطلاب، أرقام الهوية، بيانات التواصل، بيانات دخول نور، أو تفاصيل الحالات الفردية الصحية أو السلوكية أو الأسرية.
- صور التوثيق مؤقتة فقط، ومع ذلك لا ترفع صورًا يظهر فيها أشخاص يمكن التعرف عليهم.
- ملفات PDF/Word/Excel/JSON الناتجة تصبح ملفات مستقلة على جهاز المستخدم؛ يجب حفظها ومشاركتها وفق ضوابط الجهة.
- تصدير Excel وWord يتم دون مكتبات خارجية لتقليل مخاطر سلسلة التوريد؛ الملفات بصيغة .xls و.doc المتوافقة مع برامج Microsoft Office.

طريقة الرفع إلى GitHub Pages:
- ارفع جميع الملفات الموجودة داخل هذه الحزمة مباشرة إلى جذر مستودع Student-Counselor-Assistant.
- استبدلي الملفات القديمة كلها، خصوصًا app.js وservice-worker.js وindex.html وstyles.css.
- تأكد أن index.html في جذر المستودع.
- بعد النشر، نفذي تحديثًا قويًا للصفحة مرة واحدة لأن التطبيق PWA، وقد يحتاج المتصفح إلى استبدال Service Worker القديم.
- في GitHub: Settings > Pages، تأكد من تفعيل HTTPS إذا كان الخيار ظاهرًا.

تحديثات الإصدار ٥:
- الخطاب داخل التطبيق بصيغة المذكر.
- إزالة حقلي إدارة التعليم واسم المدرسة من الواجهة الرئيسية؛ أصبحا ضمن إعدادات التقرير فقط.
- استبدال العلامات الافتراضية في رأس التطبيق بشعار ملتقى التعليم التفاعلي المرفق.
- إزالة التنبيه الأصفر من التقرير المطبوع للحفاظ على نظافة التقرير، مع بقاء إرشادات الخصوصية داخل التطبيق.
- Excel أصبح XLSX حقيقيًا وWord أصبح DOCX حقيقيًا دون مكتبات خارجية.


الإصدار 6:
- Word وExcel يصدّران الأسابيع التي تم تعبئة بياناتها فقط، بدل تصدير جميع الأسابيع تلقائيًا.
- أزرار Word وExcel مستقلة داخل كل أسبوع لتصدير ذلك الأسبوع وحده مباشرة.
- تضمين شواهد التنفيذ النصية وصور التوثيق المؤقتة داخل ملفات DOCX وXLSX وقت التصدير.
- صور التوثيق تظل مؤقتة داخل التطبيق ولا تدخل في JSON ولا تُحفظ بعد تحديث/إغلاق الصفحة.


الإصدار 8:
- تحسين صور PDF: الصورة الواحدة بعرض كامل افتراضياً، وobject-fit contain لمنع القص.
- إضافة معاينة PDF قابلة لضبط الصور قبل الحفظ: صورة واحدة/صورتان، عرض كامل، احتواء/ملء، تكبير/تصغير، تدوير، وتقديم/تأخير.
- التعديلات في المعاينة مؤقتة ولا تغيّر الصورة الأصلية أو تحفظها في التطبيق.


الإصدار 9: إصلاح أدوات تعديل صور PDF على Safari/iPad عبر ربط الأحداث من التطبيق بدل JavaScript المضمّن المحظور بسياسة CSP.


الإصدار 10:
- تصدير Excel احترافي حقيقي XLSX.
- تقرير الأسبوع فقط عند التصدير من بطاقة الأسبوع.
- شعار وبيانات المدرسة ومؤشرات الأثر والشواهد والصور.
- RTL وطباعة A4 مع Fit to 1 page قدر الإمكان.
- تنظيم الصور في شبكة داخل ملف Excel.
