أبرز إضافات هذا الإصدار:
- لوحة إنجاز للأسابيع السبعة.
- زر «تم التنفيذ» لكل أسبوع.
- «جواز الأثر» ويُختم تلقائيًا عند إتمام الأسبوع.
- مؤشرات قياس الأثر لكل أسبوع: نسبة المشاركة، تحقق الهدف، رضا المستفيدين، وأبرز أثر.
- رفع صور توثيق لكل أسبوع مع معاينة وحذف.
- تقرير مستقل قابل للطباعة لكل أسبوع.
- تقرير ختامي شامل قابل للطباعة / الحفظ PDF.
- استمرار حفظ الأفكار والملاحظات والحقول محليًا.
- حقلا إدارة التعليم واسم المدرسة قابلان للكتابة والحفظ.
- التذييل: أ/ فاطمة هزازي فقط.

طريقة التحديث على GitHub Pages:
1) فكّي ضغط الحزمة.
2) ارفعي جميع الملفات الموجودة داخلها مباشرة إلى جذر المستودع Student-Guidance-Plan.
3) عند ظهور الملفات القديمة اختاري استبدالها بالملفات الجديدة.
4) لا تضعي الملفات داخل مجلد إضافي؛ يجب أن يكون index.html في جذر المستودع.
5) انتظري دقائق قليلة ثم حدّثي رابط GitHub Pages.

ملاحظات مهمة:
- بيانات النصوص والاختيارات تحفظ في المتصفح على الجهاز نفسه.
- صور التوثيق تحفظ داخل قاعدة بيانات المتصفح IndexedDB ولا تُرفع إلى خادم خارجي.
- لهذا السبب لا تنتقل صور التوثيق تلقائيًا من جهاز إلى جهاز.
- زر «طباعة الخطة / PDF» يطبع الخطة الأساسية.
- زر «تقرير الأسبوع» ينشئ تقريرًا خاصًا بالأسبوع.
- زر «التقرير الختامي» يجمع ملخص الأسابيع السبعة.
- التطبيق يعمل بدون مكتبات خارجية ويدعم PWA على GitHub Pages.
