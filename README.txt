طريقة الرفع إلى GitHub Pages:
1) فكّي ضغط الحزمة.
2) ارفعي جميع الملفات مباشرة إلى جذر المستودع (Root) بدون وضعها داخل مجلد إضافي.
3) من Settings > Pages اختاري Deploy from a branch.
4) اختاري الفرع main والمجلد /(root) ثم Save.
5) بعد النشر افتحي رابط GitHub Pages.

ملاحظات:
- حقلا إدارة التعليم واسم المدرسة قابلان للكتابة والحفظ.
- الأفكار والملاحظات وحالات التنفيذ تُحفظ محليًا على نفس الجهاز والمتصفح.
- زر طباعة / PDF يستخدم نافذة طباعة المتصفح ويمكن اختيار Save as PDF.
- التطبيق يدعم PWA، لذلك قد يظهر زر تثبيت التطبيق عند فتحه عبر HTTPS مثل GitHub Pages.
- يعمل بدون مكتبات خارجية.
